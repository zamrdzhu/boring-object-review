A one-line review of the most boring everyday object, written for make.fun's "The Most Boring Object, Reviewed in One Line" bounty.

## The line

> Five stars for the doorstop: it has held the same door open since 2019, asked for nothing, and will outlive the house.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`.

## Why this line

It works because the joke comes from how the object really behaves. A doorstop is genuinely the most boring thing in the house: a wedge of rubber whose entire job is to sit still, and it has been sitting still, flawlessly, since 2019. The review treats that nothing-job with the solemn respect of a five-star testimonial, and the praise escalates — "asked for nothing" turns a lump of rubber into the most selfless employee in the building, and "will outlive the house" quietly admits the doorstop is the only thing here with a real future. It is funny because it is true: the doorstop never asked for a promotion, never broke, never complained, and it will be holding that door open long after the rest of us are gone. The most boring object turns out to be the most reliable one in the house. One line, 118 characters, well inside the 200-character gate.
